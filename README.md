# BVGO UX prototypes

Static HTML prototypes with fictional data.

- [Notifications](notifications.html): priority, reminders, sound sample, and follow-up.
- [Action Feed](action-feed.html): 10 dummy cards and inspection response workflow.
- [Existing reference](existing.html): source-based reconstruction, not a live app.

Publish the main branch root with GitHub Pages. No build step or backend.

All response metrics are simulated session events, not experiment results. OS push, real calls/messages, authentication, and native sound behavior are not implemented. Demo portraits are illustrative public-provider images. BVGO branding is retained for this design exploration; no application source or production data is included.
